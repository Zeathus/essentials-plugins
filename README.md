# Zeathus' Essential Plugins
Various plugins I have made for Pokemon Essentials that are free to use with credit.

# Installation
To install and use a plugin, download the .zip file from the folder for the desired plugin. Extract that .zip file and place the folder inside it in the Plugins folder for your project. The extracted folder should contain a meta.txt and one or more .rb files, nothing else.

# Usage
For usage of each plugin, check the README inside of that plugin's folder.
