# Zeathus' Essential Plugins
Various plugins I have made for Pokemon Essentials that are free to use with credit.

# Installation
To install and use a plugin, download the folder for the plugin you wish to use and place that folder into your Plugins folder, with the meta.txt and other .rb files inside it.
The folder you want to download is the one with the .rb files directly inside it, not the one containing the README.md.

# Usage
For usage of each plugin, check the README inside of that plugin's folder.
